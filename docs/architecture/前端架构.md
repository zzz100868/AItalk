# 赛博聊机 · 前端架构

**适用范围**：微信小程序前端（项目根目录，非 server/）
**上游文档**：[技术方案设计](技术方案设计.md) · [前后端字段对齐表](前后端字段对齐表.md)

## 1. 数据流（当前 mock + API 双模式）

```
mockData.js (hardcoded defaults)
    ↓
app.js onLaunch → wx.login() → POST /api/auth/wx-login → 存 token
    ↓ (失败时回落)
app.js onLaunch → reads wx.Storage → merges into app.globalData
    ↓
Page onShow → common.loadUserInfo() or userStore.getProfile() → reads storage + globalData
    ↓
User edits → userStore.updateProfile() → writes storage + updates globalData + PUT /api/me
```

API 调用失败时，所有页面自动回落到本地 mock 数据，保证无后端时前端仍可独立运行。

## 2. 核心模块

| 模块 | 文件 | 职责 |
|---|---|---|
| Mock 数据 | `data/mockData.js` | DEFAULT_USER, AI_USERS (xiaoya/stitch), MATCH_CANDIDATES, MEMORY_DATA, MEMORY_REPLIES |
| API 层 | `utils/api.js` | 所有后端 API 方法封装，统一 fallback 到 mock 数据 |
| Storage 封装 | `utils/common.js` → `storage` | 内存缓存 + wx.Storage 同步。所有页面通过此模块访问，禁止直接使用 `wx.getStorageSync` |
| 用户状态 | `stores/userStore.js` | `getProfile()` / `updateProfile()` — 头像/昵称/简介的唯一数据源 |
| Tab 行为 | `behaviors/tabPage.js` | Behavior mixin，在 `onShow` 中设置 `tabBar.selected` — 所有 3 个 tab 页使用 |
| 导航 | `utils/common.js` → `goToUserHome()` | 统一的用户主页跳转，带 author 编码 |

## 3. Mock 数据策略

`data/mockData.js` 是受保护的兼容层：

- **不得修改** schema、字段名、默认用户、AI 用户、匹配候选人、记忆数据或回复结构（除非明确要求）
- 添加后端集成时，保留 mockData 作为回落数据源
- MVP 开发期间不删除 mockData

## 4. 页面与数据源

| 页面 | 数据源 | 持久化 |
|---|---|---|
| index（语音通话） | Local timer + mockData AI_USERS.xiaoya + WebSocket 语音网关 | voice_sessions/dialogue_turns 写入后端 |
| match | API `/api/match/current` → 回落 mockData.MATCH_CANDIDATES | 后端持久化 |
| memory/chat | API `/api/memory/chat` → 回落 mockData.MEMORY_REPLIES | 后端持久化 |
| memory/insights | API `/api/memory/insights` → 回落 wx.Storage('memoryInsights') | 后端 / localStorage |
| memory/archive | API `/api/memory/archive` → 回落 mockData | 后端持久化 |
| profile | userStore → wx.Storage('userProfile') + API `/api/me` | localStorage + 后端 |
| profile photos | wx.Storage('profilePhotos') + API `/api/me/photos` | localStorage + 后端 |
| accountSecurity | 硬编码 page data | 无 |
| notifications | API `/api/notifications` → 回落硬编码 (2 items) | 后端持久化 |

## 5. 跨页通信

- `app.globalData.memoryTargetTab` — 由 `endCall()` 设为 `'archive'`，memory 页 `onShow` 读取后切换子 tab，随即清除
- `userStore` — 资料变更通过 storage 传播；各页面在 `onShow` 中重新读取
- 缓存清除时的保护键：`userProfile`、`userSettings`、`memoryInsights`、`profilePhotos`

## 6. 组件

| 组件 | 用途 |
|---|---|
| `page-header` | 自定义导航栏（替代原生 nav，`navigationStyle: "custom"`） |
| `edit-modal` | 通用编辑弹窗，用于 memory 页的洞察编辑 |
| `custom-tab-bar` | 自定义底部 tab bar，3 个 tab（match/memory/profile） |

## 7. 设计系统

全局 CSS 变量定义在 `app.wxss`：

| 变量 | 值 | 说明 |
|---|---|---|
| `--bg-base` | `#faf9f7` | 基础背景色 |
| `--accent` | `#c4715a` | 主强调色（暖陶土色） |
| `--error` | `#c45a5a` | 错误/危险色 |
| 阴影 | `rgba(196,113,90,...)` | 所有阴影使用暖色调 |

- 尺寸单位统一使用 `rpx`

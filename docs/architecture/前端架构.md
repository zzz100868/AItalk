# 赛博聊机 · 前端架构

**状态**：按当前代码校准（2026-07-12）
**范围**：微信小程序根目录，不含 `server/`
**契约**：[前后端字段对齐表](前后端字段对齐表.md)

## 1. 运行形态

前端是微信小程序原生 JavaScript/WXML/WXSS 项目，由微信开发者工具编译。`app.js` 启动时调用 `wx.login` 和后端登录接口；JWT 保存在 `aitalk_token` storage key。

```text
Page/Component
  ├─ stores/*              用户与应用状态
  ├─ utils/api.js          HTTP/WS 地址、JWT、业务 API、部分 fallback
  ├─ utils/common.js       storage、媒体和导航工具
  └─ data/mockData.js      默认展示与离线回落数据
```

并非所有接口都能“完全离线”：登录、写一致性、真实语音、匹配结果、支付和推送仍依赖后端或外部平台。

## 2. 页面与数据源

| 页面 | 当前主数据源 | 当前回落/本地状态 |
|---|---|---|
| `pages/index` | 语音 WebSocket | 预写 probe_card 模拟循环 |
| `pages/match` | `/match/current`、`/match/do`、`/pay/create-order` | mock 候选和本地模拟解锁 |
| `pages/memory` chat | `/memory/chat` | 本地消息和 mock 回复 |
| `pages/memory` insights | `/memory/insights` 读取 | 编辑/删除仍只改 storage |
| `pages/memory` archive | `/memory/archive` | mock 档案 |
| `pages/profile` | `/me` + `userStore` | 资料 storage |
| profile photos | 本地文件 + `userStore` | 后端 photos API 尚未接页面 |
| `pkg-social/userHome` | `/users/:author/home` | DiceBear/本地用户资料 |
| `pkg-social/notifications` | `/notifications` | 两条本地 follow 通知 |
| account security/settings | 页面本地数据 | 无对应后端闭环 |

## 3. 状态与持久化

- `stores/userStore.js` 保存昵称、头像、简介、id 和照片等前端状态。
- `stores/appStore.js` 保存跨页短期状态，例如语音结束后跳转的 memory tab。
- `connectPage` 负责页面订阅/取消订阅 Store。
- 页面仍存在直接 storage 和本地数组逻辑，尚未完全统一到后端权威数据源。
- `data/mockData.js` 是受保护的兼容层，未经明确授权不要修改字段和默认数据。

## 4. API 层

`utils/api.js` 负责 JWT、HTTP 请求、业务方法和语音 WS URL。当前 HTTP/WS host 在文件内硬编码，开发者需要手动切换模拟器/真机地址；生产前应改为明确的环境配置。

Fallback 语义不统一：读取接口多返回 mock/null，部分写接口吞掉失败，支付 mock 还会修改本地解锁状态。后续收敛时应区分：

- 读取降级：可展示缓存或 mock，并明确数据来源。
- 写入失败：必须反馈给用户，不得假装持久化成功。
- 开发模拟：只能在非生产环境启用。

## 5. 语音前端

`pages/index/index.js` 使用 `wx.connectSocket`、`wx.getRecorderManager` 和 `wx.createInnerAudioContext`：

- 发送 16kHz 单声道 PCM frame。
- 消费 ASR 文本、TTS PCM chunk、回合结束和 session end 事件。
- 按 chunk 写临时 WAV 并排队播放。
- AI 播放期间仍允许音频上行，用于后端 barge-in 检测。
- WebSocket 失败时进入本地选择题模拟。

真实录音、播放、扬声器和打断行为必须在微信开发者工具及真机验收。

## 6. 组件与分包

- 主包：`pages/index`、`pages/match`、`pages/memory`、`pages/profile`。
- 设置分包：settings、editProfile、accountSecurity。
- 社交分包：userHome、notifications。
- 公共组件：page-header、edit-modal、skeleton。
- 自定义 tab bar：匹配、记忆库、我的，并轮询通知未读数。

## 7. 当前前端质量门禁

- 微信开发者工具编译和手动验收。
- `node --check` 可检查普通 JavaScript 语法。
- 没有前端单元测试、自动化 UI 测试、lint 或 CI。
- 根 `tsconfig.json` 当前不能通过类型检查，`stores/store.ts` 和 `utils/request.ts` 也不是当前主要业务调用层。

## 一、微信平台（必须）

### 1.1 微信小程序注册 + 认证

| 项目 | 内容 |
|---|---|
| **是什么** | 在微信公众平台注册小程序账号，完成主体认证 |
| **谁去办** | 公司法人或管理员 |
| **前提条件** | 营业执照（企业）、法人身份证、管理员微信号（已绑定银行卡） |
| **流程** | ① 访问 mp.weixin.qq.com → ② 点击"立即注册"选择"小程序" → ③ 填写邮箱、主体信息（企业选择"企业"类型） → ④ 填写管理员信息 → ⑤ 微信扫码认证 → ⑥ 对公账户打款验证 |
| **费用** | **300 元/年**（认证费，微信官方收取） |
| **耗时** | 注册 1-3 个工作日；认证 1-5 个工作日 |
| **备注** | 必须用企业主体注册，个人主体无法开通微信支付 |

### 1.2 小程序类目审核

| 项目 | 内容 |
|---|---|
| **是什么** | 小程序后台选择服务类目，微信审核通过后才能发布 |
| **谁去办** | 开发者（你）协助，公司提供资质文件 |
| **前提条件** | 营业执照 + 可能的特殊行业许可证 |
| **流程** | ① 登录 mp.weixin.qq.com → ② 设置 → 基本设置 → 服务类目 → ③ 添加类目并上传资质文件 → ④ 等待审核 |
| **费用** | **0**（但获取资质文件可能需要费用，见下方备注） |
| **耗时** | 类目审核 1-3 个工作日；如需办理 ICP 许可证则额外 30-60 工作日 |
| **⚠️ 风险点** | 类目必须与实际功能一致。提交前按微信最新官方类目和资质要求核验，不应使用与产品功能不符的类目规避审核。 |

**类目备选方案：**

| 方案 | 类目 | 所需资质 | 审核难度 |
|---|---|---|---|
| A（推荐 MVP） | 工具 > 信息查询 | 营业执照即可 | 低 |
| B | 教育 > 在线教育 | 营业执照即可（非学科类） | 低 |
| C | 社交 > 陌生人交友 | 营业执照 + ICP 许可证 + 网络文化经营许可证 | 高 |
| D | 社交 > 婚恋服务 | 营业执照 + ICP 许可证 | 高 |

### 1.3 微信支付商户号

| 项目 | 内容 |
|---|---|
| **是什么** | 微信支付商户平台账号，用于收款（会员、解锁权益等） |
| **谁去办** | 公司法人或管理员 |
| **前提条件** | 小程序已完成企业认证 |
| **流程** | ① 登录小程序后台 → ② 微信支付 → 开通 → ③ 填写商户资料（营业执照、法人身份证、对公账户） → ④ 微信支付审核 → ⑤ 商户号与小程序的 APPID 绑定 → ⑥ 设置支付密钥 |
| **费用** | 开通免费；交易费率 **0.6%**（每笔交易微信收取） |
| **耗时** | 申请 1-5 个工作日 |
| **备注** | MVP 阶段支付为 P2 优先级，可先不开通，但建议提前准备 |

### 1.4 微信内容安全接口

| 项目 | 内容 |
|---|---|
| **是什么** | 微信官方提供的文字/图片/音频内容审核 API |
| **谁去办** | 开发者（技术配置） |
| **前提条件** | 小程序已注册 |
| **流程** | ① 登录小程序后台 → ② 开发 → 开发管理 → 接口设置 → ③ 开通 `security.msgSecCheck`（文字检测）、`security.mediaCheckAsync`（图片/音频检测） |
| **费用** | **免费** |
| **耗时** | 即时开通 |
| **备注** | 社交类小程序建议务必接入，否则提审可能被拒 |

### 1.5 小程序服务器域名配置

| 项目 | 内容 |
|---|---|
| **是什么** | 在小程序后台配置 request/websocket/upload/download 合法域名 |
| **谁去办** | 开发者 |
| **前提条件** | 已购买服务器和域名、已完成 ICP 备案、已配置 HTTPS |
| **流程** | 登录小程序后台 → 开发 → 开发管理 → 服务器域名 → 填写 `request合法域名`、`socket合法域名`、`uploadFile合法域名`、`downloadFile合法域名` |
| **费用** | **0** |
| **耗时** | 即时（每月可修改 5 次） |
| **备注** | 必须 HTTPS，不支持 IP 地址，WebSocket 必须用 `wss://` |

## 三、服务器与基础设施

### 3.1 云服务器（推荐阿里云或腾讯云）

| 项目 | 内容 |
|---|---|
| **是什么** | 运行 NestJS 后端服务 + 语音网关独立进程 |
| **谁去办** | 开发者选配，公司购买 |
| **流程** | ① 选择云厂商 → ② 注册并企业认证 → ③ 选购计算实例 → ④ 仅对公网开放 80/443，Node.js 端口置于反向代理和内网之后 |
| **推荐配置** | 先以 2 核 4GB、受支持的 LTS Linux 为压测起点，再按 HTTP 与语音并发调整 |
| **费用** | 约 **100-200 元/月**（按量付费）；包年约 **1000-2000 元/年** |
| **耗时** | 购买即时 |

### 3.2 云数据库 PostgreSQL（推荐云厂商托管）

| 项目 | 内容 |
|---|---|
| **是什么** | 主数据库，存储用户、聊天记录、匹配、人格档案等全部数据 |
| **谁去办** | 开发者选配，公司购买 |
| **流程** | ① 云厂商控制台 → ② 数据库 → ③ 创建 PostgreSQL 实例 → ④ 配置白名单 → ⑤ 获取连接地址 |
| **推荐配置** | PostgreSQL 15+，容量与连接数按压测结果选择；当前 schema 不要求 pgvector |
| **费用** | 约 **50-150 元/月**（入门配置）；包年约 **500-1500 元/年** |
| **耗时** | 创建即时 |

### 3.3 云数据库 Redis（当前非依赖）

| 项目 | 内容 |
|---|---|
| **是什么** | 可选的缓存和任务队列基础设施；当前代码未使用 Redis/Bull，只有引入持久任务或分布式协调后才需要 |
| **谁去办** | 开发者选配 |
| **流程** | ① 云厂商控制台 → ② 缓存 → ③ 创建 Redis 实例 → ④ 配置白名单 |
| **推荐配置** | 1GB 标准版 |
| **费用** | 约 **30-80 元/月**（入门配置） |
| **耗时** | 创建即时 |

### 3.4 域名注册

| 项目 | 内容 |
|---|---|
| **是什么** | API 服务的域名，小程序只认域名不认 IP |
| **谁去办** | 公司购买（以公司名义注册） |
| **流程** | ① 任意域名注册商（阿里云/腾讯云/GoDaddy）→ ② 搜索并购买域名 → ③ 完成域名实名认证 → ④ DNS 解析到云服务器 IP |
| **费用** | **50-100 元/年**（.com / .cn） |
| **耗时** | 购买即时；实名认证 1-3 个工作日 |

### 3.5 SSL 证书

| 项目 | 内容 |
|---|---|
| **是什么** | HTTPS 加密证书，小程序要求所有接口必须 HTTPS |
| **谁去办** | 开发者配置 |
| **流程** | ① 云厂商控制台 → ② SSL 证书 → ③ 申请免费证书（Let's Encrypt 或云厂商免费 DV 证书）→ ④ 域名验证（DNS 或文件验证）→ ⑤ 部署到服务器 |
| **费用** | **0**（免费 DV 证书，90 天续期）或 **1000-5000 元/年**（商业证书） |
| **耗时** | 申请 10 分钟 |
| **备注** | MVP 用免费 DV 证书即可 |

### 3.6 ICP 备案

| 项目 | 内容 |
|---|---|
| **是什么** | 工信部要求的网站/服务器备案，**国内服务器必须先备案后使用** |
| **谁去办** | 公司负责人（需要人脸识别验证） |
| **前提条件** | 已购买域名 + 云服务器；域名实名认证完成；服务器在境内 |
| **流程** | ① 云厂商控制台 → ② 备案管理 → ③ 填写主体信息（公司营业执照、法人信息、负责人信息）→ ④ 上传资料（营业执照照片、法人身份证、负责人身份证、域名证书）→ ⑤ 人脸识别核验 → ⑥ 提交管局审核 → ⑦ 等待审批 |
| **费用** | **0**（云厂商免费代办，不含幕布拍照等杂费） |
| **耗时** | **15-20 个工作日**（各地管局不同，上海/广东较快约 10 天，北京/浙江约 15-20 天） |
| **⚠️ 关键路径** | 备案是最耗时的单项，**建议立即启动**，与小程序的开发调试并行推进 |

## 四、法规与合规

### 4.1 隐私政策 + 用户协议

| 项目 | 内容 |
|---|---|
| **是什么** | 小程序审核必须提交的法律文本，告知用户数据收集范围、用途、第三方数据共享 |
| **谁去办** | 公司提供初稿（可由律师审核），开发者在小程序中展示 |
| **流程** | ① 撰写《隐私政策》和《用户服务协议》→ ② 小程序首次启动时弹窗展示 → ③ 在小程序后台"功能设置"中填写隐私协议链接 → ④ 提审时提交 |
| **费用** | **0**（自行撰写）或 **2000-5000 元**（律师审核） |
| **耗时** | 撰写 1-2 天；律师审核 3-5 个工作日 |
| **要点** | 必须注明：收集麦克风权限用途（语音通话）、存储权限用途（缓存聊天记录）、是否与第三方（火山引擎）共享语音/文本数据 |

### 4.2 算法备案（如适用）

| 项目 | 内容 |
|---|---|
| **是什么** | 网信办要求的算法推荐服务备案，适用于个性化推荐类、生成合成类算法 |
| **谁去办** | 公司（开发者配合技术说明） |
| **流程** | ① 访问 beian.cac.gov.cn → ② 注册主体账号 → ③ 填写算法信息（算法原理、数据输入输出、安全评估） → ④ 提交 → ⑤ 等待审核 → ⑥ 获取备案编号并在应用内展示 |
| **费用** | **0** |
| **耗时** | 准备材料 1-2 周；审核 30-60 工作日 |
| **备注** | MVP 阶段如果用户量小可暂缓，但上线后应尽早启动。匹配算法属于"个性化推荐类"，LLM 对话属于"生成合成类" |

### 4.3 网络文化经营许可证（如适用社交类目）

| 项目 | 内容 |
|---|---|
| **是什么** | 文化和旅游部要求的许可证，适用于经营性互联网文化活动（含社交/直播） |
| **谁去办** | 公司 |
| **前提条件** | 注册资本 ≥ 100 万（各省不同）；营业执照经营范围含"互联网文化服务" |
| **流程** | ① 向各省文旅厅提交申请 → ② 提交材料（营业执照、验资报告、人员社保、网站域名等）→ ③ 审批 |
| **费用** | 自行办理约 **500-2000 元**（工本费）；代理约 **5000-15000 元** |
| **耗时** | **30-60 个工作日** |
| **备注** | 是否需要以及适用范围必须根据实际业务、主体所在地和最新官方要求向专业人员确认。 |

### 4.4 增值电信业务经营许可证（ICP 许可证，如适用）

| 项目 | 内容 |
|---|---|
| **是什么** | 工业和信息化部要求的许可证，适用于经营性网站/应用（含会员收费、虚拟币充值等） |
| **谁去办** | 公司 |
| **前提条件** | 注册资本 ≥ 100 万（部分省）；社保人员 ≥ 3 人；经营范围含"增值电信业务" |
| **流程** | ① 向各省通信管理局提交申请 → ② 材料审核（营业执照、验资报告、3 人社保缴纳证明、网站备案）→ ③ 审批 |
| **费用** | 自行办理约 **2000-5000 元**；代理约 **8000-20000 元** |
| **耗时** | **30-60 个工作日** |
| **备注** | 同上，仅社交类目需要。注意与 ICP 备案区分——ICP 备案（3.6）是必须的，ICP 许可证是经营性的 |

## 建议行动顺序

1. **本周**：公司注册域名 → 开通云服务器 → 提交 ICP 备案（与开发并行）
2. **本周**：注册微信小程序（企业认证）→ 确定使用哪个类目
3. **本周**：注册火山引擎账号（企业认证）→ 开通 ASR/TTS/LLM 服务
4. **第 2 周**：撰写隐私政策 + 用户协议
5. **第 3 周**（备案通过后）：配置 SSL → 部署后端 → 配置小程序服务器域名
6. **第 4 周**：提审小程序 → 灰度发布 → 正式上线
